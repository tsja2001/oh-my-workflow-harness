# 文档模板集

十个模板：主文档、问题清单、确认结果汇总、接口测试说明、配置项核查表、开发交接、接口文档、测试报告、评审报告、代码复盘与学习。占位符用 `<>` 标注。

所有文档放在 `docs/需求/<主题名>/`，文件名遵守 **AGENTS.md §5** 的六段制：`<段号>-<中文短名>-<工具代号>.md`
（`00` 输入 / `10` 想清楚 / `20` 动过之后 / `30` 别人来验 / `50` 交还理解 / `90` 其它；工具代号 cc/codex/oc，无后缀=用户写的）。
**只增不覆盖**：同阶段重做就新建带轮次或子题后缀的文件，并在开头写一行"本文取代 xx，取代原因：yy"。
每份文档头部必带四行：日期、工具、当前状态一句话、下一步该做什么。
