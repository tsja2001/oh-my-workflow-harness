description: >-
  AI代开发企业级后端需求的全流程工作法：用户不懂目标语言/框架（如Java微服务），AI负责全部技术执行（读代码、查库、写代码、编译、提交），
  用户负责拿AI整理的问题去和产品/领导/同事对接。覆盖需求拆解→问题收敛(带逐字话术)→答案回收→开工侦察→照样板纯增量开发→
  隔离编译验证→干净提交test→Jenkins部署与curl链路验证，以及多AI阶段接力的文档交接规范。只要用户在企业代码库（如 work-wsl / zhaocai 招采平台）
  提出任何开发类请求——贴了一段产品需求、问"这个需求怎么做/怎么拆"、要整理问同事的问题、要写代码/建表/提交/部署/测接口/跑通流程——都要使用本skill，
  即使用户没提"流程"两个字。用户纯粹闲聊或只问概念解释时不用。
