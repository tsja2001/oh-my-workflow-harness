本文件只是**项目级加载器**，正史在仓库里（便于所有 AI 工具共享和 git 管理）。触发后立即：

1. 读 `skills/industry-perspective/SKILL.md`（相对仓库根）——什么时候进入、怎么读他稀疏的提问、五条法则、已验证的失败模式、每次结束的进化义务。
2. 读 `skills/industry-perspective/references/校准记录.md`——**必读**。这是用户历次原话纠偏的证据，决定讲法。
3. 读 `skills/industry-perspective/references/行业地图.md`——已沉淀的行业知识、可用锚点清单、已讲过什么、下一步可钻什么。**别重复讲过的。**
4. 需要引用他自己系统的事实时，从 `ai-docs/系统地图.md` 和 `docs/需求/18集采平台下一步规划/50~52` 取现成结论，**不要重新查库**——这个模式不该花时间做技术侦察。

`AGENTS.md` 的红线依然生效（尤其红线 5「核实，不猜」，在本模式的变体见正史法则 5）。

**对话结束前必做**：只要用户说了任何一句让你调整讲法的话，照抄原话追加进 `校准记录.md`。这是本 skill 唯一的进化机制。

不要只凭本加载器的描述行动；一切以正史文件为准。
