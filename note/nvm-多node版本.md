# nvm 多 Node 版本自动切换

## 解决什么问题
系统默认 Node 是 v14(给老项目用),但这个仓库要 Node 22 才能跑 `pnpm install`。
又不能改默认版本,怕影响别的项目。

## 干了什么

1. **建 `.nvmrc`**(仓库根目录),内容就一行:
   ```
   22
   ```
   告诉 nvm 这个仓库用 Node 22。

2. **在 `~/.zshrc` 和 `~/.bashrc` 里加了一个 `cdnvm` 钩子**:
   `cd` 进任何一个含 `.nvmrc` 的目录,自动 `nvm use` 切到那个版本;离开后自动切回默认版本。

## 现在的效果

| 操作 | Node 版本 |
|------|----------|
| 开新终端(默认状态) | v14 |
| `cd` 进本仓库 | 自动 v22 |
| `cd` 出去 | 自动回 v14 |

所以在本仓库可以直接 `pnpm install`,别的项目完全不受影响。

## 注意
- `.nvmrc` 文件里**只写版本号**(`22`),不要写成 `echo "22" > .nvmrc` 这种命令文字。
- `.nvmrc` 本身不会自动切版本,**靠的是 `cdnvm` 这个 cd 钩子**。钩子只在 `~/.zshrc` / `~/.bashrc` 里,换电脑要重新加。
- 改完 rc 文件后要 `source ~/.zshrc`(或开新终端)才生效。
