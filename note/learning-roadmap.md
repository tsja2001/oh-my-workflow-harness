# 招采项目学习路线规划

本文档用于规划学习节奏。目标不是把 Java 微服务所有技术都学透，而是让你能理解项目架构、定位功能模块、排查 bug，并能有效指挥 AI 辅助开发。

## 学习目标

你最终需要具备这些能力：

- 知道一个页面/接口大概率属于哪个后端服务。
- 能从接口 URL 找到 Controller、Service、Mapper、SQL。
- 能判断一个功能改动应该改启动工程、业务模块、API 模块、Feign 模块还是配置中心。
- 能看懂常见 Java/Spring/Maven 报错，知道下一步查哪里。
- 能让 AI 帮你写具体实现，但你自己能判断代码位置、影响范围和风险。

## 推荐节奏

### 阶段 1：项目地图

时间建议：1 到 2 天。

你需要做到：

- 能说清 `01zhaocai-end` 和 `03zhaocai-start` 的关系。
- 能找到每个微服务的启动模块。
- 能知道一个服务默认端口、服务名、启动类在哪里。
- 能理解 `*-web-jar`、`*-api`、`*-feign-api` 大概分别干什么。

### 阶段 2：请求链路

时间建议：2 到 4 天。

你需要做到：

- 根据接口路径用 `rg` 找 Controller。
- 看懂 Controller 参数和返回值。
- 跟到 Service、Mapper、XML SQL。
- 识别 DTO、VO、Entity、Enum、Repository。

### 阶段 3：Bug 定位

时间建议：2 到 4 天。

你需要做到：

- 看懂 Java 异常栈。
- 知道网关、认证、业务服务、数据库、Feign、Nacos 配置分别可能导致什么问题。
- 能把问题定位到具体服务、具体接口、具体 SQL 或具体配置。

### 阶段 4：新增功能

时间建议：持续练习。

你需要做到：

- 在已有模块里新增一个查询接口。
- 修改一个业务状态流转。
- 增加一个字段并知道涉及哪些层。
- 判断是否需要新增 Feign API、权限、字典、Nacos 配置或 SQL。

### 阶段 5：技术栈补课

时间建议：穿插进行。

只补够用知识：

- Java 基础：集合、泛型、异常、Stream。
- Spring MVC：Controller、参数绑定、JSON 返回。
- Spring Bean：Service、依赖注入、配置类。
- MyBatis/MyBatis-Plus：Mapper、XML、动态 SQL。
- Maven：父 POM、子模块、dependency tree。
- Nacos：配置中心、服务发现。
- Feign：跨服务调用。

## 每次学习时怎么问 AI

建议以后按这种格式提问：

```text
我要学习/修改的功能：
我知道的页面或接口：
我猜测的模块：
当前目标或报错：
我希望你带我做到哪一步：
```

这样 AI 可以直接按项目地图定位，而不是每次重新扫整个仓库。
