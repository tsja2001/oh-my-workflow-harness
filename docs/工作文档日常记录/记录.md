# 发版流程
## 先发uat
### 前端
1. 准备一个新分支，只提取业务相关的代码提交上去，注意不要把test/prod环境配置相关的代码拿出来合并到uat上，推到远程
2. 到gitlab上发起mr，审核人兰宇
3. 在Jenkins重启
### 后端
1. 第一步、第二步、第三步相同
2. 配置字典、配置导出模板、配置菜单，等一系列要在test配置的都要在后端配置
3. 执行后端sql
