```java
	/**
	 * 把规则引擎上下文里的值递归规范化成 JSONObject / JSONArray。
	 *
	 * fastjson 1.x 的 JSON.toJSON() 会把嵌套对象也递归转成 JSONObject，规则模板依赖了这个行为
	 * （模板里写的是一层层 .get("字段名")）。fastjson 2.x 只转最外层，Map 的值和数组保持原样，
	 * 于是模板对嵌套实体调 get(String) 就报"没有找到 get(java.lang.String)"。
	 * 这里手动把 1.x 的行为补回来；标量（日期/数字/布尔/字符串/枚举/java.time）原样保留，
	 * 不走文本序列化，所以不会把 Date 变成时间戳或字符串。
	 */
	public static Object toRuleContextValue(Object o) {
		if (o == null) {
			return null;
		}
		if (o instanceof Map) {
			JSONObject r = new JSONObject();
			for (Map.Entry<?, ?> e : ((Map<?, ?>) o).entrySet()) {
				r.put(String.valueOf(e.getKey()), toRuleContextValue(e.getValue()));
			}
			return r;
		}
		if (o instanceof Collection) {
			JSONArray r = new JSONArray();
			for (Object e : (Collection<?>) o) {
				r.add(toRuleContextValue(e));
			}
			return r;
		}
		if (o instanceof Object[]) {
			JSONArray r = new JSONArray();
			for (Object e : (Object[]) o) {
				r.add(toRuleContextValue(e));
			}
			return r;
		}
		if (isRuleScalar(o)) {
			return o;
		}
		Object j = JSON.toJSON(o);
		if (j instanceof Map || j instanceof Collection || j instanceof Object[]) {
			return toRuleContextValue(j);
		}
		return j;
	}

	/** 标量：保持原始 Java 类型不做任何转换 */
	private static boolean isRuleScalar(Object o) {
		if (o instanceof CharSequence || o instanceof Number || o instanceof Boolean
				|| o instanceof Date || o instanceof Character) {
			return true;
		}
		Class<?> c = o.getClass();
		return c.isPrimitive() || c.isEnum() || c.getName().startsWith("java.time.");
	}
```

需要补的 import：`java.util.Collection`、`java.util.Date`、`java.util.Map`、`com.alibaba.fastjson.JSONArray`。
