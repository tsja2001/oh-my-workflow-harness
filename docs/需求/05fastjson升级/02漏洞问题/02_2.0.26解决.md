1. 方案一 安全模式参数

在每个服务的Dockerfile或者deploy-docker.yaml加
ENV JAVA_TOOL_OPTIONS="-Dfastjson2.parser.safeMode=true"

2. 方案二 代码开启安全模式

每个服务的启动类 main 第一行加：
System.setProperty("fastjson2.parser.safeMode", "true");


3. 方案三：

开发一个专门启动fastjson安全模式的Spring Boot Starter发不到nexus，在scm-cloud-starters-web/pom.xml声明
配置好启动时间，让在启动其他模块之前，让System.setProperty("fastjson2.parser.safeMode", "true")生效
等到下一个正式版2.0.63发布之后可以撤掉
