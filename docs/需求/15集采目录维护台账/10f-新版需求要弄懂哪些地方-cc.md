# 第三部分 · ★ 这次开发，你要弄懂这 8 块

> 标记说明：🟢 你已经通了 ｜ 🟡 见过但不牢 ｜ 🔴 还没碰过

## 🟢 1. 物料 / 类目分级

**是什么**：一棵四级树（2/4/6/8 位编码），物料是 12 位。
**这次哪条用到**：3.1「支持选择到末级」、6.2「取末级类目再往上」。
**你的进度**：**已通**，看 `10e` 第一部分和你自己写的 `12b`。

## 🟢 2. 集采台账现在怎么匹配

**是什么**：两条路——按 12 位物料编码点名，或按类目整片（只在物料编码留空时启用，且现在被硬绑在二级）。
**这次哪条用到**：整个 §3 和 6.2 都是在改这个。
**你的进度**：**已通**，看 `10e` 第二、三部分。

## 🟡 3. 组织架构：集团 / 二级集团(BU) / 企业 / 区域

**是什么**：金隅集团 → 13 个二级集团（BU001~BU011 等）→ 854 家企业。**"区域"不是组织树上的一层，是贴在每家企业身上的一个标签**（`belong_plate_code`）。
**这次哪条用到**：§4「影响范围编码」——填 BU 编码还是区域编码，全看你选了哪个集采目录层级。
**不懂会怎样**：影响范围这一列会填错，而且分不清"区域"为什么不能像选公司那样选。
**现在的坑**：**73% 的企业没有区域码**，所以"区域集采"这一档今天在 uat 上根本跑不通。
**想深入就说**：「讲讲组织和区域」

## 🔴 4. 集采目录层级三档，和影响范围怎么配对

**是什么**：这次新增的必填字段，三个值——集团集采 / 二级集团集采 / 区域·企业集采。它决定了**这条规矩管谁**。
**这次哪条用到**：§2.1、§4、§5、6.3，还有 6.5 的三条审批分支。**这是新版需求的主心骨。**
**不懂会怎样**：整个需求你都看不懂，因为后面每一条都在说"如果层级是 X 就怎样"。
**一句话预习**：

```
集团集采      → 影响范围填「所有 BU」    → 全集团都得走集采
二级集团集采  → 影响范围填「指定 BU」    → 那个 BU 下面的企业走集采
区域/企业集采 → 影响范围填「区域编码」   → 贴了这个区域标签的企业走集采
```

**想深入就说**：「讲讲集采目录层级」 ← **建议第一个补这块**

## 🟡 5. 三个单据：采购计划 / 采购方案 / 非平台录入

**是什么**：集采规矩最终是作用在这三种单子上的。`10d` 第二章的"八幕"讲过，但你可能记不牢它们的先后和区别。
**这次哪条用到**：6.1「这三个地方的物料明细行都要自动回写三个字段」。
**不懂会怎样**：不知道字段该加在哪三个页面、三个页面的数据从哪来（采购方案的物料行是从采购计划带过来的，不是重新选的）。
**想深入就说**：「讲讲这三种单子的关系」

## 🔴 6. 是否集采 / 是否强管控 / 审批流三条分支

**是什么**：单据表头上的两个"章"，决定这张单子走哪条审批路线。
**这次哪条用到**：6.4、6.5 的 ①②③ 三条分支。
**⚠️ 但你只需要懂到"要给华姐提供什么字段"** —— 群里明说了审批流调整是郭小华的活。你的边界是：**把 `是否集采`、`集采目录层级`、`是否强管控` 三个值算准、存对、传给工作流**。
**不懂会怎样**：给工作流传的变量名/取值对不上，华姐画不了分支。
**想深入就说**：「讲讲强管控和那三条审批分支」

## 🔴 7. 状态 / 失效时间 /「管后不管前」

**是什么**：台账的行不再物理删除，改成打上"失效"和失效时间；已经提交过的老单子不受新规矩影响。
**这次哪条用到**：§2.3、§2.4，还有开头那句"根据启用时间，管后不管前"。
**不懂会怎样**：会把"删除"做成真删除，历史数据对不上账；也分不清"启用时间"和"创建时间"的差别（`11b` A5 问的就是这个，产品还没答）。
**想深入就说**：「讲讲状态和管后不管前」

## 🔴 8. 期初上线 = 初始化 + 新业务自动取值

**是什么**：上线那天，历史的 7343 行台账数据要补上新增的必填字段（层级、强管控），补什么值得产品给。
**这次哪条用到**：开头 §4。
**不懂会怎样**：上线当天台账里一半字段是空的，新逻辑直接不生效。
**现在已知的坑**：那 7343 行里 uat 实测 610 行（1701 润滑剂）中就有 125 条物料库查无此编码、125 条已停用。
**想深入就说**：「讲讲期初初始化」
