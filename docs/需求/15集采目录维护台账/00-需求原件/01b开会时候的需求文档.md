# 集采目录管控	系统现状：
招采平台中通过【集采范围台账】判断集团级集采范围，支持按照二级类目或物料编码进行管控；
未来管理需求：
1、集采目录管控：目录管理到末级（同云采）；完成物料目录到末级的梳理；
2（补充）集采目录层级管理：一级集采（全集团）、二级集团集采（按bu）、区域或企业级集采（要想一下区域怎么玩）
2、目前全集团只统一到二级，优先参考水泥集团现有类目标准，
3、是否强管控、按照bu、进行管控、启用时间、失效时间；(管后不管前)；
4、期初上线=初始化+新业务自动取值； 							

# 功能实现	
1、现有功能【集采范围台账】改造；
2、增加“集采目录层级”、“是否强管控”、“失效时间”、“状态”字段；
2.1、集采目录层级：新增，必填，可选内容为：集团集采、二级集团集采、区域/企业集采；
2.2、是否强管控：新增，必填，可选内容包含是、否；强管控的，采购方案编制时/非平台录入允许修改“是否集采”字段信息，如果是改成否，执行新的审批流程（向上一级审批）；弱管控的，允许修改“是否集采”信息，修改后执行原流程；



是否集采=是&是否强管控=是（&集采目录层级=集团集采）：企业---二级集团---集采执行单位---总部；
是否集采=是&是否强管控=是（二级集团集采、区域/企业）：企业；”是否集采“改成“否”，向上一级审批：企业/区域发起---二级集团；二级集团发起-----总部；
是否集采=是&是否强管控=否（二级集团集采、区域/企业）：企业；”是否集采“改成“否”，按原流程执行；

2.3、失效时间：新增，只读，记录删除时间；
2.4、状态：新增，只读，内容包含：生效、失效；新增后，状态默认“生效”，如果删除后状态更改为“失效”；对后续影响：采购方案提交或者非平台录入提交时，物料编码属于集采台账的同时增加“状态”的判断条件；
3、是否集采：后续采购方案、采购计划、非平台录入，物料明细行中的类目只要属于“集采范围台账”自动回写“是否集采、集采目录层级”（如果归属不同的物料层级如何处理？？？？？）；
3、集采类目编码：支持选择到末级（有3、有4，类目编码清单？？---目前各二级集团2级类目已统一，3、4级未统一？？？？
4、影响范围编码：如果选择“集团集采”，“影响范围编码”录入所有二级集团BU编码，所有企业均执行集采逻辑；如果选择“二级集团集采”，录入指定的二级集团BU编码，指定BU编码的下属企业执行此集采逻辑；如果是“区域/企业集采”，录入指定的区域的组织编码【企业与区域的关联关系见右图】，区域编码下的关联企业均执行此集采逻辑；
如果同一类目属于集团级，是否还允许属于其他二级集团级或者区域级？？？？

5、集采执行单位编码：集采目录层级为“二级集团、区域/企业”的无需配置集采执行单位；
6、类目处理逻辑：
先按物料编码校验，物料编码不存在取末级类目，末级类目没有取上级；
