## 2. 现有 7343 条数据，两个新字段填什么
我的默认：层级 = 集团集采，强管控 = 否

强管控填"是"的话，这七千多条对应的单子上线第二天全走最严那档，
全集团审批链一夜之间集体变长。

顺带：约 600 条死数据（物料查不到 207 + 已停用 389），建议标失效，不物理删。


## 3. 弱管控 + 集团集采，那个框能不能改
需求 6.5 三条分支：

  强 + 集团            不允许修改
  强 + 二级集团/区域   可改，提报上一级审批
  弱 + 二级集团/区域   可直接改成非集采
  弱 + 集团            ？？ 没写

而期初默认正好是"集团集采 + 弱管控"，
上线第一天七千多条全落在这个没定义的格子里。

我的默认：能改，走原流程。


## 4. 二级集团/区域层级的单子，谁做采购方案
需求 §5 说这两档不配集采执行单位。
但方案页面那道拦截照旧拦本企业，让"联系集采执行单位"
=> 没有执行单位可联系，机电公司也筛不到，这单没人能接。

我的默认：拦截只对集团集采生效，二级集团/区域本企业自己做。

这条猜错了上线当天不暴露，要等业务真配了二级集团的规矩才炸。


## 5. 判重怎么算 + 撞了听谁的
判重：类目 + 物料 + 层级 + 影响范围，四个全同才算重复
      失效行不占判重位置

撞了：170101 冀东水泥配一条、唐山区域也配一条，唐山的企业提单听谁的？
      我的默认：范围越窄越优先（区域 > 二级集团 > 集团）
                同层级取最后录的

注意：需求 6.2 只写了"是否集采"怎么算，
      没写命中两条时另外两个字段（层级、强管控）取哪条。
      这是需求的洞，必须问。

# 五、6.2 和 6.3 的关系（自己看的，别问产品）

不是一件事。中间还夹着一件需求没写的事，就是上面问题 5。

一张单子 10 行物料，每行都要走：

  步骤1  纵向找：物料码 → 末级类目 → 逐级往上，找到就停     6.2 写了
  步骤2  横向挑：找到的那级上有两条都命中，用哪条          原文没写 = 问题5
         ↓ 这一行拿到自己的 是否集采/层级/强管控
  步骤3  跨行汇总：10 行各有各的层级，表头只能填一个        6.3/6.4 写了
         层级取最小（集团赢），强管控有强取强

两个方向反着，因为回答的问题不同：

  步骤2  这一行归谁管    范围越窄越优先（区域赢）
         像"全国统一价"和"唐山门店特价"，付门店价，更具体的赢
  步骤3  这一单按什么走  层级越高越优先（集团赢）
         像一车货有普通件和危险品，整车按危险品标准运，最严的赢

一个是行的事，一个是单的事。
