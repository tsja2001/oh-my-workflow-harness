## 一、给你看的需求

### 1. 要解决什么问题

招采现有“添加物料”弹窗虽然左边有树，但线上接口只展示到二级，无法直观看见“金属材料 → 黑色金属 → 型材 → 螺纹钢”这类完整路径。

本次做一个独立的本地网页工具，把招采主数据中的完整物料类目拉出来重新组装成树，并允许继续查询树下的具体物料。它只读 test/UAT，不提供新增、修改、删除能力。

### 2. 使用者和使用场景

| 使用者 | 场景 | 工具要回答的问题 |
|---|---|---|
| 需求分析/产品沟通 | 研究“末级类目” | 这条类目在第几级、父子路径是什么、是不是末级 |
| 开发/测试 | 核对环境差异 | test 和 UAT 是否缺类目、改名、停用状态不一致 |
| 业务人员 | 从类目找物料 | 某个类目下面有哪些具体物料、编码和规格是什么 |
| 数据排查 | 看主数据质量 | 是否有断链、重复编码、停用节点、各层数量是否异常 |

### 3. 功能范围

#### 3.1 环境与登录

- 支持 `test` / `uat` 一键切换，页面明确显示当前环境。
- 本地服务复用工作区 `scripts/api.sh` / `scripts/auth.sh` 自动登录和刷新 token。
- 浏览器永远拿不到账号、密码、token；凭据仍只存在 `ai-docs/creds.env` 和受控缓存。
- 不支持 prod，服务端对环境参数做白名单校验。

#### 3.2 完整类目树

- 展示 2/4/6/8 位编码对应的一至四级类目。
- 同时展示停用节点；可按“全部/启用/停用”过滤。
- 支持编码或名称模糊搜索；搜索命中时保留并展开祖先路径。
- 支持层级过滤、只看末级、全部展开、全部收起、刷新。
- 顶部展示类目总数、末级数、一至四级数量、断链数、重复编码数。
- 点击节点展示：完整路径、层级、状态、父级、直接子级数、全部后代数、采购方式、单位、同步时间、类目说明。

#### 3.3 物料查询

- 可全局查询，也可从当前类目查询；选择一至四级类目时都包含它下面的物料。
- 查询条件：综合关键词、物料编码、物料名称、长描述、短描述、类目编码、页码、每页条数。
- 列表展示：类目编码/名称、物料编码/名称、物料描述、完整类目路径、单位、采购组织方式、更新时间。
- 支持复制编码/路径、导出当前查询页 CSV。
- 页面明确说明公司接口只返回启用中的 MDM 物料，避免把“查不到”误解成不存在。

#### 3.4 test/UAT 对比

- 给出仅当前环境存在、仅另一环境存在、名称不同、状态不同的数量和明细。
- 点击某个类目后，显示该节点在两个环境中的逐字段对比。

### 4. 不做什么

- 不改 `scm-vue-all-mdm` 现有页面，不接入菜单、岗位或 Jenkins。
- 不新增后端 Java 接口；复用现有只读查询接口。
- 不查询或修改生产环境。
- 不提供类目/物料/集采台账的增删改导入，避免研究工具成为第二套维护入口。
- 不解决原集采需求里尚未确认的审批、判重、区域数据等业务问题。

### 5. 验收标准

1. test/UAT 都能自动登录并拉到完整平铺类目数据，再在浏览器中组装出多级树。
2. test 能看到 6 位、8 位节点，例如能定位到 `15010112 螺纹钢`。
3. 搜索“螺纹钢”能显示完整祖先链，选择该类目能查出具体 12 位物料编码。
4. test/UAT 切换后，数量和名称按目标环境刷新，不混用缓存。
5. 查询条件、分页、CSV 导出、空结果和接口错误均有可理解反馈。
6. `npm run check` 通过；本地服务只监听 `127.0.0.1`。

### 2. 项目落点

- 新项目：`docs/需求/15集采目录维护台账/物料树/material-tree-explorer/`
- 技术栈：React + TypeScript + Vite + Ant Design。
- 本地 BFF：Node.js 原生 HTTP；开发时作为 Vite 中间件，构建后同时托管静态文件与 `/api/*`。
- 工作区脚本调用：使用 `child_process.spawn` 参数数组调用，禁止拼 shell 字符串。

### 3. 安全边界

- 只允许固定的两个 SCM 查询接口和 `test|uat`；前端不能透传任意方法/路径。
- 请求体限制大小，查询字符串限制长度，子进程设置超时和输出上限。
- 服务只绑定回环地址；错误响应不得包含凭据、token 或完整环境变量。
- 类目接口做短时内存缓存；按环境分开，手动刷新可绕过缓存。

### 4. 自行拍板记录

| 决定 | 理由 | 猜错代价 |
|---|---|---|
| 做独立工具，不塞进旧 Vue 工程 | 用户目的先是研究数据；旧工程要求 Node 14，当前环境是 Node 22 | 小，后续仍可把成熟交互移植回旧页面 |
| 从分页接口拿平铺数据后前端组树 | 当前部署的真正完整树接口 404，旧树接口又主动砍级；分页接口一次可拿全量 | 小，接口字段已实测 |
| “末级”按无子节点判定 | 每条分支深度不同，不能按 8 位判断 | 无 |
| 物料查询按类目码长度映射到大/中/小/小小类字段 | 后端现有查询实现就是这个约定 | 小 |
| 第一版只读 | 研究工具不应绕过正式维护流程 | 无 |
