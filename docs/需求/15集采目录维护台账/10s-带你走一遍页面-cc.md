## 0. 先更正：T1「没有新增」是我说重了

**你的判断是对的。**

导入代码就是**循环 insert，没有先清空**——所以你下一份模板、**只填一行**、点导入，
**就是新增一行**。这个路径完全走得通，我上一版把它说成"没有新增"，不准确。

**改一条也不用全导出全删除。** 实际是两步：

```
在列表上勾中那一行 → 删除 → 把改好的那一行填进模板 → 导入
```

**只针对单行，不影响其他 7342 行。** 我上一版写得像要全表重来，那是夸大了。

### 那我为什么还建议加个「编辑」按钮？——理由降级了，但还在

不是"改不了"，是**"改完会留下三个副作用"**：

| # | 副作用 | 为什么要紧 |
|---|---|---|
| 1 | **创建时间会变成今天** | 这次要拿「创建时间」当「启用时间」用（`10q` Q8）。改一次强管控，这条规矩就变成"今天才开始生效"，**历史依据就断了** |
| 2 | **删除改成"标记失效"之后，每改一次就多留一条失效行** | 表只涨不减；而云采采集那条链路是**空条件全表扫**，数据越多越慢 |
| 3 | **删了再导，可能直接撞判重录不进去** | 除非判重口径明确写"只跟生效的比"（`10q` Q1 后半句就是为这个） |

## 1. 先认认这四个页面

| # | 页面 | 谁在用 | 点「提交」的时候，跟集采有关的事 |
|---|---|---|---|
| ① | **采购计划编制** | 企业采购员（小王） | 查一次台账 → 盖「是否集采」的章 → **不拦你，照常提交** |
| ② | **（待采购池）** | 没有页面，是后台的中转站 | 计划**审批通过**时，每行掉进池子；如果是集采，**顺手写一笔"这活归谁"** |
| ③ | **采购方案编制** | 企业的采购经办 | 查一次台账 → 盖章 → ⚠️ **满足条件会直接拦住你，不让提交** |

| ⑤ | **集采采购计划（供应商端）** | **机电公司**登录看 | 从池子里筛出"归我的"，统一去采购 |

**只有 ③ 会拦人。这是理解 P1 的关键。**

## 2. 场景 A：今天一张正常的集采单子，从头走到尾

**背景**：台账里有一条「柴机油 → 集团集采 → 执行单位 = 机电公司」。

```
第1步  小王（唐山某水泥厂采购员）打开【采购计划编制】
       填：柴机油 100 桶，10月要
       点【提交】
         ↓
       系统拿柴机油去台账查 → 命中
       → 单子上盖章「是否集采 = 是」
       → 提交成功，进入审批
         ↓
第2步  计划审批通过
         ↓
       系统把这张计划的每一行，各丢一条进【待采购池】
       因为「是集采」→ 系统去台账把「集采执行单位」抄下来
       → 在池子那条记录上写「这活归：机电公司」
         ↓
第3步  小王想接着自己做采购方案，打开【采购方案编制】
       从池子里挑出柴机油那一行，点【提交】
         ↓
       ⛔ 被拦住了，弹一句：
          「集采物资采购且有计划，请联系集采执行单位组织采购」
       → 提交中止。这活不该小王干。
         ↓
第4步  机电公司以【供应商身份】登录，打开【集采采购计划】页面
       页面自动筛：「是集采」 且 「归我的」
       → 看到了小王那条柴机油
       → 机电公司统一组织采购
```

**这条链是通的**，因为第 2 步写进去的"归机电公司"，正好被第 4 步筛出来了。

**"集中采购"的"集中"，就集中在这儿**——不是集中在方案里，是集中在机电公司手里。

## 3. 场景 B：P1 的死局 —— 换成"二级集团集采"，链条在哪断

**背景**：这次要新加的层级。台账里录一条
「柴机油 → **二级集团集采** → 影响范围 = 冀东水泥 → **集采执行单位：不用填**（需求 §5 明说的）」。

同一个小王，走同一条路：

```
第1步  【采购计划编制】提交柴机油
         ↓
       查台账 → 命中 → 盖章「是集采」
       ✅ 这一步没问题
         ↓
第2步  计划审批通过，行掉进【待采购池】
       因为「是集采」→ 系统去台账抄「集采执行单位」
         ↓
       💥 断点一：那一栏是空的（需求说了不用填）
          → 池子上"这活归谁"这一格 = 空
          （更糟：现在这段代码没判空，可能直接报错，审批通过这一步就崩）
         ↓
第3步  小王打开【采购方案编制】，挑出柴机油，点【提交】
         ↓
       ⛔ 断点二：还是被同一句话拦住
          「集采物资采购且有计划，请联系集采执行单位组织采购」
          → 可是**根本没有执行单位可联系**
         ↓
第4步  机电公司打开【集采采购计划】页面
       页面筛的是「归我的」
         ↓
       💥 断点三：池子上那格是空的，不等于"机电公司"
          → 机电公司**根本看不到这张单**
```

### 结果

```
小王：提交不了方案（被拦）
机电公司：看不到这张单（没写归它）
其他人：也没人被指定

→ 这张单子卡死在池子里，谁也接不了
```

### ⚠️ 这个坑最阴的地方

**它不会报错，也不会在上线当天暴露。**

上线当天所有台账数据都是「集团集采」（期初默认值），链条是通的。
**要等业务真的开始配"二级集团集采"的规矩，第一张这样的单子提上来，才会撞上。**
那时候大家早就以为功能上线成功了。

### 我的建议

**那道拦截，只对「集团集采」层级生效。** 二级集团 / 区域层级的，**本企业自己做方案，不拦。**

理由：「集采执行单位」这一栏本来就是给集团集采用的（今天 7343 行里 7326 行填的都是机电公司）。
**需求既然说二级集团不用填执行单位，就等于说这一档不走"交给别人代办"这条路。**

### 要问产品的，其实就一句话

> **"二级集团层级的集采单子，本企业能不能自己做采购方案？如果不能，交给谁？"**

## 4. 混采是什么？（P2）

### 4.1 一句话

**一张单子里，既有集采的东西，又有不集采的东西。**

```
小王的一张采购计划：
  第1行  柴机油 100桶     ← 台账里有 → 是集采
  第2行  拖把  20把       ← 台账里没有 → 不是集采
  第3行  抹布  50条       ← 台账里没有 → 不是集采
```

### 4.2 为什么系统不喜欢它

因为「是否集采」这个章**盖在整张单子的表头上，只有一个**。

一张单子里三行两种情况，**这个章到底盖"是"还是"否"？说不清楚。**
所以今天的做法是：**干脆不让你这么提**，弹个框拦住，让你把它拆成两张单子。

### 4.3 现在的实际情况：那个弹框是死的

代码大意是这样：

```js
弹出确认框，然后等用户点
   点【确定】 → 什么都不做
   点【取消】 → 什么都不做
```

它在**等一个永远不会来的结果**。

**实际体验**：弹框出来了，你点确定——没反应；点取消——没反应；关掉弹框——页面还是卡着。
**提交流程永远停在这一步，只能刷新页面重来，而且刚填的东西可能白填。**

三个页面（采购计划、采购方案、非平台录入）**一模一样，全是这个毛病**。

> 今天很少有人撞上，是因为台账只管 7 个类目、绝大多数单子压根没盖过章。
> **管到末级类目之后，这种单子会天天出现。**

### 4.4 那为什么这次它变成一个"待定问题"？

因为新需求里那两句话，读起来像是**改口了**：

> 6.3 集采目录层级：取物料明细区**最小层级**属性
> 6.4 是否强管控：如果多物料，**有强取强**

"取最小"、"有强取强"——**这两句的前提是"一张单子里多行物料情况不一样"**。
那到底是：

- **(a)** 仍然禁止混采，这两句只用来处理"**多行都是集采**、但有的归集团、有的归板块"的情况？
- **(b)** 改成允许混采了，弹框该去掉？

**我的建议：(a)，保持禁止混采**，只把那个死锁修好（弹框改成能正常关掉的拦截提示）。
理由：一个章说不清两种情况；而且这是现有行为，不改动静最小。

**这条为什么要问**：它决定那个弹框是**删掉还是改掉**，三个前端页面的改法全看它。

## 5. 强管控 / 弱管控是什么？审批流咱做不做？

### 5.1 两个章在说两件事

| 章 | 在回答什么 | 谁说了算 |
|---|---|---|
| **是否集采** | 这批东西**归不归**集采管 | 系统查台账，自动判 |
| **是否强管控** | 归了之后，**能不能商量** | 台账那条规矩上写着 |

### 5.2 强、弱差在哪

```
强管控 = 硬规定
   "你想不走集采？行，但得多找一级领导签字"

弱管控 = 软规定
   "你想不走集采？改一下就行，流程照旧"
```

⚠️ **强管控不等于"不许改"。** 它是"改可以，但代价更大"。
真正"不许改"的只有一种——下面分支①。

### 5.3 三条分支（用小王走一遍）

小王提交单子，系统盖章「是集采」。接下来看**这条规矩是谁定的 + 硬不硬**：

**① 集团定的 + 强管控 → 连改都不让改**
> 集团总部的硬规定，谁也别想绕。
- 页面上「是否集采」那个框**是灰的，点不动**
- 审批路线最长：**企业 → 二级集团 → 机电公司 → 总部**

**② 板块/区域定的 + 强管控 → 能改，但改了要多报一级**
> 是硬规定，但不是集团定的，有商量余地，只是得惊动上级。
- 可以把「是否集采」改成"否"
- 一改，审批就升级：企业/区域发起的 → 报到二级集团；二级集团发起的 → 报到总部

**③ 板块/区域定的 + 弱管控 → 能改，流程不变**
> 软规定，改了就改了，跟平时买东西一样。

一句话记住：**谁定的规矩越高、越硬，你想绕开就越难。**

### 5.4 还有一条容易漏的：这个框只能往一个方向改

```
是  →  否   ✅ 可以（代价看上面三条）
否  →  是   ❌ 不行
```

**不在集采范围里的东西，采购员也不能自己勾成"是集采"。** 集采范围是台账说了算。

### 5.5 ⭐ 「审批流程咱要做吗」——分两半，一半做一半不做

这是你问的重点，单独说清楚：

```
┌──────────── 咱们做的 ────────────┐   ┌─── 华姐做的 ───┐

  ① 算出三个值                        画那三条分支图
     是否集采 / 集采目录层级 / 是否强管控
                                        "①要经过哪4级、
  ② 存到单据表里                        ②比原来多爬哪一级、
     （4张表各加2列，现在根本没地方存）  ③照原样走"
                                        —— 在 DPS 那个平台上
  ③ 前端：显示这两个新字段                 拖拖拽拽画出来
     并决定「是否集采」那个框灰不灰

  ④ 把三个值递给工作流平台
     （照抄现成的 11 行代码）

└─────────────────────────────────┘   └────────────────┘
                              ↑
                     交接面就在这一条线
```

**翻译成大白话：**

> **"几级审批、谁审、谁签字"——不是我们做的，是华姐在流程平台上画的图。**
> **"凭什么走这条路而不是那条路"——那三个判断依据，是我们算出来递过去的。**

群里原话是「流程表单这块**你负责给审批流提供字段**，华姐负责审批流调整」——
关键就在"提供字段"四个字：**字段不会自己冒出来**，得先有人算出来、存下来、显示出来。

### 5.6 所以「弱管控改成否要不要审核」这个问题，答案是什么？

按文档（6.5 分支③）：**弱管控改成否，走原流程，不额外审。**
按产品会上说的：**执行新流程（向上一级审批）。**

**两版需求文档都写"原"，口头说的是"新"。这是 P3，必须当场问。**

**我的建议：以文档为准，走原流程。**
理由很简单——**如果弱管控改了也要多审一级，那它跟强管控就没区别了**，三条分支塌成两条，弱管控这个字段就没意义了。

### 5.7 顺带两个我建议加的（P5、P6）

**P5 改成"否"的时候，要不要填个理由？**
现在页面上没这个框。但分支②是要**多找一级领导签字**的——
那位领导打开单子只看到一个"否"，**不知道为什么改**，这级审批就是走过场。
**我的建议：加一个必填的理由框。** 成本很小，但它是那级审批唯一的判断依据。

**P6 改成"否"之后，「集采目录层级」这个章还留着吗？**
**我的建议：留着。**
「层级」说的是"这东西归哪一级管"（台账定的客观事实），「是否集采」说的是"这单最后走没走集采"（这张单子的结果），**两回事**。
留着，报表才能算出「集团集采范围内有多少单被改成了非集采」——**这恰恰是做管控最想看的数字**。

## 6. 一页总结

### 更正

- **T1 我说重了**：一行的 Excel 导进去就是新增；改一条也只要"删那一行 + 导那一行"。
  加编辑按钮**降级为锦上添花（🟢），不是卡点**，会上时间紧可以不问。

### 三件事的关系

```
混采（P2）      = 一张单子里有的集采、有的不集采 → 现在弹框拦，但弹框是死的
强弱管控        = 台账那条规矩硬不硬 → 决定改成"否"的代价
P1 那个死局     = 二级集团层级没有执行单位，方案被拦、机电公司又看不到 → 谁也接不了
```

### 会上就问这四句（不用背话术，意思到就行）

1. **"二级集团层级的集采单子，本企业能不能自己做采购方案？如果不能，交给谁？"**（P1）
2. **"一张单子里既有集采又有非集采，还是像现在这样禁止吗？"**（P2）
3. **"弱管控的改成非集采，到底走原流程还是要多审一级？文档写的是原流程，您上次说的是新流程。"**（P3）
4. **"改成非集采的时候，要不要让他填个理由？"**（P5）
