# 一、先想一个最朴素的问题

集团这么大——13 个板块、854 家公司。

**"这个东西必须集中起来买，不许自己买"，这句话是谁说了算？**

这一整个需求，说白了就是在回答这一个问题。

---

# 二、今天的世界：只有一种规矩

今天的集采范围台账里，**每一条规矩都是集团总部定的，而且管所有人**。

```
总部说：轴承必须集采
   ↓
854 家公司全都得听
```

台账里 7342 行，"管谁"那一栏填的**一模一样**，全是"所有板块"。没有第二种可能。

## 这样有两个麻烦

**麻烦一：板块想自己管点东西，做不到。**

冀东水泥说"我们板块买办公用品也想集中起来买"——
今天一填进台账，就变成全集团 854 家都得跟着走。**没有"只管我自己这一片"的选项。**

**麻烦二：领导问不出数。**

年底开会，领导问："集团层面集采做了多少钱？各个板块自己集采了多少？"

**答不上来。** 因为每条规矩都没记"我是谁定的"——所有钱混在一起，分不开。

---

# 三、所以这次要给每条规矩上个"户口"

每条规矩要回答两个问题：

| 问题 | 对应的新字段 |
|---|---|
| **你是谁定的？** | 集采目录层级 |
| **你管谁？** | 影响范围编码 |

**这两个字段的全部意义就是这两句话。** 别被名字唬住。

---

# 四、三种"谁定的"，三个场景

## 场景 A：总部下令

> 集团总部说：**全集团买柴机油都必须集采。**

- 谁定的？→ **集团**
- 管谁？→ **所有 13 个板块，854 家公司**

## 场景 B：冀东水泥自己下令

> 冀东水泥说：**我们板块买柴机油要集采，别的板块我不管。**

- 谁定的？→ **二级集团**（冀东水泥就是一个"二级集团"，也叫板块、BU）
- 管谁？→ **冀东水泥底下那 258 家公司**

## 场景 C：唐山那一片自己下令

> 唐山区域说：**我们这几家买柴机油要集采。**

- 谁定的？→ **区域**
- 管谁？→ **算作"唐山区域"的那 8 家公司**

---

# 五、⚠️ 这里有个坎：什么叫"算作唐山区域的公司"

这是最容易卡住的地方，单独讲。

## 5.1 组织结构上，根本没有"区域"这一层

集团的组织结构就两层：

```
金隅集团
  ├── 冀东水泥（板块）
  │      ├── 唐山某公司
  │      ├── 石家庄某公司
  │      └── …… 一共 258 家
  ├── 混凝土集团（板块）
  │      └── …… 86 家
  └── …… 一共 13 个板块，854 家公司
```

**看见没有？板块底下直接就是公司，中间没有"区域"这一层。**

## 5.2 那"区域"在哪？——贴在每家公司身上的一张标签

```
唐山某公司  【所属区域：唐山区域】   ← 一张标签
石家庄某公司【所属区域：石家庄区域】
北京某公司  【所属区域：（空白）】   ← 很多公司压根没贴
```

所以"唐山区域集采"的意思是：

> 系统去 854 家公司里，**挨个翻标签**，把贴着"唐山区域"的都找出来，这些公司要走集采。

## 5.3 这就带来一个现实问题

**854 家公司里，622 家（73%）的标签是空白的。**

而且贴了标签的那些，标签本身也乱——36 种标签里有一半根本不是区域，
是把公司名字当区域贴上去了（比如有 60 家公司的"所属区域"写的是"冀东发展集团有限责任公司"，那是个公司不是区域）。

**结论：区域这一档，今天做出来也没法验证。** 只有冀东发展那 60 家标签是齐的。
这件事产品 8 月 19 号就答应去补，到今天还没补。

# 六、你问的那个疑问：**"二级集团岂不是只能填自己的板块？"**

你这个直觉是对的，但要换个角度看。

## 6.1 关键在于：**台账不是各个板块自己录的**

你可能默认了这样一个画面：

> 冀东水泥的人登录系统 → 进台账 → 录一条规矩 → 系统知道"哦这是冀东水泥录的"

**但实际不是这样。** 台账是**平台运维在后台统一录的**（菜单挂在"运维中心"底下）。
系统看到的只是一个运维人员在录数据，**它根本不知道这条规矩背后是谁的意思**。

## 6.2 所以"谁定的"必须**手动写**

正因为系统不知道，所以才要你手填两栏：

```
这条规矩的级别是   → 二级集团级
这条规矩管的是     → 冀东水泥
```

**这两栏合在一起，才表达出"这是冀东水泥定的规矩"。**
系统里并没有一个字段直接叫"谁定的"——它是靠这两个字段拼出来的。

## 6.3 那能不能填别人的板块？

**需求上没禁止。** 原文只说"录入指定的二级集团编码"，没说只能填一个、也没说必须是自己。
而且那一栏本来就是能填多个的（今天就填着 12 个）。

所以理论上可以出现："级别=二级集团，管的是 冀东水泥 + 混凝土集团"——**两个板块联合集采**。

**但这样一来，审批该报给哪个板块？** 需求里的审批路线写的是"往上报给二级集团"，只有一个。
**这是需求没想到的情况，要问产品。**

# 七、你问的另一个：**"为什么不填企业编码？"**

这个问得更准——**需求确实漏了这一半。**

三档的名字分别是：

| 档 | 名字 | 需求说了怎么填吗 |
|---|---|---|
| 一 | 集团集采 | ✅ 填所有板块 |
| 二 | 二级集团集采 | ✅ 填指定板块 |
| 三 | 区域 / **企业** 集采 | 区域说了 ✅，**"企业"没说** ❌ |

第三档的名字里明明写着"企业"，但需求里只交代了区域怎么填，**"企业"那半边一个字没提**。

所以业务如果说"我只想管这三家公司"——**现在没地方写。**

这一条一定要问产品：**是漏了，还是"企业"那半边这期不做？**

# 八、再讲那个"集采执行单位"

换个角度理解它，就不乱了。

## 8.1 规矩定完了，接下来是**谁去买**

总部说"全集团买轴承都要集采"。可是——

**总不能 854 家各买各的吧？那还叫什么集中采购。**

所以要指定一家公司，替大家统一去买。今天指定的是**唐山冀东机电设备有限公司**（简称机电公司）。

> **"集采执行单位"这一栏，填的就是"跑腿的那家公司"。**

台账 7343 行里，7326 行填的都是机电公司。

## 8.2 为什么只有集团级要填这一栏

**理由一（业务上）**：

- 总部定的规矩 → 全集团的事 → 得有一家统一去买 → **机电公司**
- 冀东水泥自己定的规矩 → **它自己板块内部找人买就行了**，不用惊动机电公司
- 唐山区域自己定的，同理

**理由二（流程上，这条更硬）**：

看审批路线就明白了——

```
集团集采的单子：  企业 → 板块 → 【机电公司】 → 总部     ← 机电公司要签字
二级集团的单子：  企业 → 板块                            ← 路线上根本没有机电公司
区域的单子：      企业/区域 → 板块                        ← 同上
```

**只有集团级那条线上，机电公司是一个审批节点。** 另外两档的流程里压根没这个人——
所以那两档填了也没人用。

# 十、你只要记住这五句

1. **这个需求就是在回答一件事：这条集采规矩，是谁定的、管谁。**
2. **今天所有规矩都是"总部定的、管所有人"，没有第二种。这次是要把另外两种造出来。**
3. **组织只有两层：13 个板块 + 854 家公司。"区域"不是一层，是贴在公司身上的一张标签，而且 73% 的公司没贴。**
4. **"谁定的"必须手填，因为台账是运维在后台统一录的，系统不知道背后是谁的意思。**
5. **"集采执行单位"是"跑腿的那家公司"（机电公司）。只有集团级的审批路线上有它这一环，所以只有集团级要填。**
