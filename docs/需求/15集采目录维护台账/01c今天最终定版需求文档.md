# 集采目录管控	系统现状：
招采平台中通过【集采范围台账】判断集团级集采范围，支持按照二级类目或物料编码进行管控；
未来管理需求：
1、集采目录管控：目录层级清单可参考云采；
2、集采目录层级三级管理：一级/集团集采、二级/二级集团集采、三级/区域或企业集采；
3、是否强管控、按照bu、进行管控、启用时间、失效时间；(根据启用时间，管后不管前)；
4、期初上线=初始化+新业务自动取值； 							

# 功能实现

## 下面这部分在群里原话：

“小杨，按照昨天沟通后，又整理了下需求, 这块是【集采台账改造】部分；--这块预计11号完成”
1、现有功能【集采范围台账】改造；

2、增加“集采目录层级”、“是否强管控”、“失效时间”、“状态”字段；
2.1、集采目录层级：新增，必填，可选内容为：集团集采、二级集团集采、区域/企业集采；
2.2、是否强管控：新增，必填，可选内容包含是、否；
2.3、失效时间：新增，只读，记录删除时间；
2.4、状态：新增，只读，内容包含：生效、失效；新增后，状态默认“生效”，如果删除后状态更改为“失效”；对后续影响：采购方案提交或者非平台录入提交时，物料编码属于集采台账&状态属于“生效”；

3、集采类目编码：
3.1、支持选择到末级；类目编码参考云采【路径：品类管理-后台类目管理】；
3.2、集采类目维护时，优先判断“集采目录层级”，同一类目/物料编码属于”集团集采”，则此类目及下级/物料不允许再维护其他层级；
3.3、集采目录层级不属于“集团集采”，同一类目/物料可以属于不同的二级集团或者区域；


4、影响范围编码：如果选择“集团集采”，“影响范围编码”录入所有二级集团BU编码，所有企业均执行集采逻辑；如果选择“二级集团集采”，录入指定的二级集团BU编码，指定BU编码的下属企业执行此集采逻辑；如果是“区域/企业集采”，录入指定的区域的组织编码【企业与区域的关联关系见右图】，区域编码下的关联企业均执行此集采逻辑；

5、集采执行单位编码：“集采目录层级“”为“二级集团、区域/企业”的无需配置集采执行单位；

6、业务流程改造：
6.1、采购方案、采购计划、非平台录入，物料明细行中的类目只要属于“集采范围台账”自动回写“是否集采、集采目录层级、是否强管控”；

6.2、“是否集采“”判断逻辑：先按物料编码校验，物料编码不存在取末级类目，末级类目没有取上级；若属于则为“是”；

6.3、集采目录层级：采购方案编制/非平台录入界面增加“集采目录层级”字段，取物料明细区最小层级属性；

6.4、是否强管控：采购方案编制/非平台录入界面增加“是否强管控”字段，如果多物料，有强取强；

6.5、采购方案编制时/非平台录入界面如果”是否集采”默认“否”则不允许修改。如果“是否集采”默认“是”则允许修改；如果是强管控，是否集采改成否，执行新的审批流程（向上一级审批）；弱管控的，是否集采改成“否”，修改后执行原流程；

①是否集采=是&是否强管控=是&集采目录层级=集团集采：企业---二级集团---集采执行单位---总部；“是否集采”不允许修改；

②是否集采=是&是否强管控=是&集采目录层级=二级集团集采、区域/企业：企业；”是否集采“改成“否”，向上一级审批：企业/区域发起---二级集团；二级集团发起-----总部；

③是否集采=是&是否强管控=否&集采目录层级=二级集团集采、区域/企业：企业；”是否集采“改成“否”，按原流程执行；

7、强管控的必须进行物料类目标准化；！！！！！
