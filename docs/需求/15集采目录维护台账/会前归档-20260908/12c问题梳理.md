### 采购计划编制：
* 现在情况：
1. 都是非集采/非集采					=> 正常编制
2. 有集采+非集采			=> 集采和非集采不允许同时采购
* 新版本
1. 都是非集采					=> 正常编制
2. 有集团/二级集团集采/区域集采混着 => 集采目录层级：集团集采
3. 有集采+非集采			=> 集采和非集采不允许同时采购


### 采购方案编制
* 现在情况：
1. 都是非集采					=> 正常编制
2. 都是集采 					=> 每行都有计划号 → 拦住 / 有行没计划号 → 正常提交
3. 有集采+非集采			=> 集采和非集采不允许同时采购

* 新版本：
1. 都是非集采					=> 正常编制
2. 都是集团集采				=> 集采物资采购且有计划，请联系集采执行单位组织采购；对应集采公司编制采购计划？
3. 都是二级集团集采/都是区域集采 => 本企业自己做
4. 混合：
4.1 非集采+集采 			=> 集采和非集采不允许同时采购
4.2 集团集采 + 二级集团集采/区域集采 => 按集团集采走
