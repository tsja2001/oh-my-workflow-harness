# 2. 集采类目规则
当前规则：
类目编码 + 物料编码：只管这一条物料（精准点名）
二级类目编码 + 物料编码留空：✅ 整片管住该二级下所有物料
新版本要做：
可以录入类目编码 => 管所有物品
一样可以录入类目编码 + 物料编码 => 只管这一个物品

# 5. 是否集采 / 是否强管控 / 审批流三条分支 
要买一个东西：

① 集团定的 + 强管控 → 连改都不让改
「是否集采」那个框是灰的，点不动。审批路线最长：企业 → 二级集团 → 机电公司 → 总部

② 板块/区域定的 + 强管控 → 能改，但改了要多报一级
企业改的报到板块，板块改的报到总部

③ 板块/区域定的 + 弱管控 → 能改，流程不变
改完跟平时买东西一样

主要为工作流提供变量，代码业务不多
