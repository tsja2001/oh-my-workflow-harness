# 需求：配置煤炭重点坑口日指标

1、一级菜单“集采业务管理台账”下增加二级菜单“煤炭重点坑口日指标管理”（这个等同事提交了前端代码再说前端的事情，后端不用管，正常开发测试接口就行）；此功能支持录入、导出、删除及修改功能；
2、”集采管理-执行单位集采管理岗”有此菜单权限（人的操作，我联系同事配置）；
3、执行单位需每日24点前完成“前一日重点坑口及港口煤炭价格”；发布后自动更新【集采驾驶舱-煤炭重点坑口日指标】（这个自动更新的功能，我理解是产品的表述，从技术角度来说，是不是提交后数据库数据更新了，集采驾驶舱调用API就能获取到最新数据。你参考一下现在的驾驶舱页面，你要确定一下现在是不是接口也都有了）；
4、驾驶舱-煤炭重点坑口日指标（右中）（这个截图在 `docs/需求/台账需求2/驾驶舱页面截图.png`，和第3条说的是同一个表），按照最新的发布日显示当日价格；
5、新增：招采录入后直接发布；
6、修改：支持数据修改，修改内容包括“集采执行单位、坑口1名称、坑口1日价格、坑口2名称	、坑口2日价格、坑口3名称、	坑口3日价格、坑口4名称、坑口4价格”；
7、删除：点击【删除】，可对本行进行删除；
8、修改后更新“发布时间和操作人”；
