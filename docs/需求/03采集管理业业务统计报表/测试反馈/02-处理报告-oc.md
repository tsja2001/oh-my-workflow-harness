# 云采板块名称显示全称 · 处理报告

> 日期：2026-08-11（处理）/ 2026-08-12（uat 验证）
> 工具：oc

## 原问题

UAT 集采管理业务统计报表"板块"列出现全称（如"北京金隅新型建材产业化集团有限公司"），不在所属板块字典里；都是云采（YC）数据。

## 原因

云采写入 ES 时把组织系统的"所属板块名称"原样写入，没像其他四路（招采/FP/JD/MT）那样按板块编码查 Owningplate 字典换成标准名。组织系统里这个字段本身有脏值（有的填公司全称、有的填简称），所以页面出现了字典外的名称。筛选按编码走，不受影响，纯显示问题。

## 解决

1. 修复代码：`scm-order-all` `CentralizedProcurementReportServiceImpl` 写入前按 `buCode` 查 Owningplate 字典取标准名，查不到才回退原值（与其他四路同一写法）。分支 `fix/jicai-report-umb-yang@f4e45eeff`，已合入 test/uat。
2. 重跑同步覆盖存量：调 `/d/business/order/centralizedProcurementReport/syncToEs` 重跑 2026-01-01 至今（ES 主键=订单号_物料编码，同 id 覆盖，不重复）。
