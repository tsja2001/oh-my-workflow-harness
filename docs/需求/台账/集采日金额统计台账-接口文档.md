# 集采日金额统计台账 - 接口文档

> **历史文档，当前接口清单以 `21-接口文档-codex.md` 为准。** 2026-07-10 已删除台账专用组织查询 `queryOrgForSelect`；下文保留其原始记录，仅供追溯，不得再按该地址联调。

## 基础信息

| 项目 | 值 |
|------|-----|
| 服务名 | `scm-source-web` |
| 路径前缀（网关） | `/gateway/e/business/source` |
| 请求方式 | 全部 `POST` |
| Content-Type | `application/json` |
| 鉴权 | 请求头 `Authorization: bearer <token>` |
| 数据表 | `sc_collection_daily_amount_ledger` |

## 通用响应格式

```json
{
    "status": true,
    "code": "000000",
    "data": {},
    "msg": "",
    "timestamp": 1783562721544
}
```

- `status`: 布尔，true 成功 / false 失败
- `code`: 字符串，`"000000"` 表示成功
- `data`: 具体返回值，各接口不同
- `msg`: 错误信息

# 二、字典/下拉接口

## 1. 组织查询（执行单位 / 采购企业 共用）

```
POST /gateway/e/business/source/collectionDailyAmountLedger/queryOrgForSelect
```

两个下拉框调同一个接口，同一份候选列表。返回中带有 `belongBuCode` 和 `belongBuName`，可用于自动填充所属板块。

### 请求

```json
{ "keyword": "唐山" }
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `keyword` | String | 否 | 组织名称模糊匹配，传空或不传返回全部（861 家） |

### 响应

```json
{
    "status": true,
    "code": "000000",
    "data": [
        {
            "orgCode": "13030000",
            "orgName": "唐山冀东水泥股份有限公司唐山分公司",
            "belongBuCode": "BU002",
            "belongBuName": "冀东水泥"
        },
        {
            "orgCode": "10310046",
            "orgName": "唐山冀东水泥外加剂有限责任公司重庆分公司",
            "belongBuCode": "BU002",
            "belongBuName": "冀东水泥"
        }
    ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `orgCode` | String | 组织编码，用于新增/修改的 `executeUnitCode` 或 `purchaseCompanyCode` |
| `orgName` | String | 组织名称，用于新增/修改的 `executeUnitName` 或 `purchaseCompanyName` |
| `belongBuCode` | String | 所属板块编码，与板块字典 code 一致 |
| `belongBuName` | String | 所属板块名称 |

> **前端省事技巧**：选完采购企业后，直接拿 `belongBuCode` 自动填「所属板块」字段，板块显示名以板块字典为准。

# 三、台账 CRUD 接口

## 4. 分页查询列表 + Excel 导出

```
POST /gateway/e/business/source/collectionDailyAmountLedger/queryPageList
```

### 请求参数（普通查询）

```json
{
    "currentPage": 1,
    "limit": 10,
    "model": {
        "ledgerNo": "",
        "executeUnitCode": "",
        "purchaseCompanyCode": "",
        "categoryCode": "",
        "buCode": "",
        "statisticDateArr": ["2026-07-01", "2026-07-09"]
    }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `currentPage` | int | 是 | 当前页码，从 1 开始 |
| `limit` | int | 是 | 每页条数 |
| `model` | object | 否 | 筛选条件，不传或 {} 表示查全部 |
| `model.ledgerNo` | String | 否 | 流水号，模糊查询 |
| `model.executeUnitCode` | String | 否 | 执行单位编码，精确匹配 |
| `model.purchaseCompanyCode` | String | 否 | 采购企业编码，精确匹配 |
| `model.categoryCode` | String | 否 | 类目编码，精确匹配 |
| `model.buCode` | String | 否 | 所属板块编码，精确匹配 |
| `model.statisticDateArr` | String[] | 否 | 统计日期区间 `[开始, 结束]`，格式 `yyyy-MM-dd` |

### Excel 导出

在请求体**外层**增加三个字段即可触发导出，返回 `xlsx` 文件流（需用 blob 下载）：

```json
{
    "currentPage": 1,
    "limit": 10,
    "model": {},
    "exportRequest": "true",
    "exportFileName": "集采日金额统计台账",
    "exportTemplateCode": "collection-daily-ledger-export"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `exportRequest` | String | 是 | 固定值 `"true"` |
| `exportFileName` | String | **否** | 下载文件名（不含扩展名），默认 `"exportFileName"`；后端已配置默认模板 |
| `exportTemplateCode` | String | **否** | 后端注解已设默认值 `"collection-daily-ledger-export"`，不传也会正常导出 |

> 导出时 `model` 中的筛选条件同样生效，支持按条件导出全部数据。后端自动将 limit 设为最大值。

Excel 列（当前模板 9 列）：

| 集采日金额统计流水号 | 集采执行单位 | 集采类目 | 统计日期 | 采购企业 | 采购金额（含税） | 所属板块 | 发布时间 | 创建人 |
|---|---|---|---|---|---|---|---|---|

## 5. 新增台账

```
POST /gateway/e/business/source/collectionDailyAmountLedger/add
```

### 请求参数

```json
{
    "executeUnitCode": "JDGS",
    "executeUnitName": "机电公司",
    "categoryCode": "1501",
    "categoryName": "钢材",
    "statisticDate": "2026-07-09",
    "purchaseCompanyCode": "TSFGS",
    "purchaseCompanyName": "唐山分公司",
    "taxAmount": 888.88,
    "buCode": "SNJT",
    "buName": "水泥集团"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `executeUnitCode` | String | 是 | 执行单位编码（来自组织查询接口的 `orgCode`） |
| `executeUnitName` | String | 是 | 执行单位名称（来自组织查询接口的 `orgName`） |
| `categoryCode` | String | 是 | 集采类目编码（来自类目字典的 `code`） |
| `categoryName` | String | 是 | 集采类目名称（来自类目字典的 `name`） |
| `statisticDate` | String | 是 | 统计日期，格式 `yyyy-MM-dd` |
| `purchaseCompanyCode` | String | 是 | 采购企业编码（来自组织查询接口的 `orgCode`） |
| `purchaseCompanyName` | String | 是 | 采购企业名称（来自组织查询接口的 `orgName`） |
| `taxAmount` | BigDecimal | 是 | 交易金额（含税/元） |
| `buCode` | String | 是 | 所属板块编码（来自板块字典的 `code`，或采购企业 `belongBuCode`） |
| `buName` | String | 是 | 所属板块名称（来自板块字典的 `name`，或采购企业 `belongBuName`） |

> 以下字段由后端自动生成，**不需要传**：`ledgerId`、`ledgerNo`、`createBy`、`createByName`、`createTime`、`updateBy`、`updateByName`、`updateTime`、`publishTime`、`publishBy`、`publishByName`。

### 响应

```json
{
    "status": true,
    "code": "000000",
    "data": "JCRJE-20260709-005"
}
```

- `data`：返回生成的流水号，格式 `JCRJE-yyyyMMdd-XXX`

## 6. 修改台账

```
POST /gateway/e/business/source/collectionDailyAmountLedger/modify
```

### 请求参数

```json
{
    "ledgerId": "2075038425069625346",
    "executeUnitCode": "JDGS",
    "executeUnitName": "机电公司",
    "categoryCode": "1501",
    "categoryName": "钢材-已修改",
    "statisticDate": "2026-07-09",
    "purchaseCompanyCode": "TSFGS",
    "purchaseCompanyName": "唐山分公司",
    "taxAmount": 999.99,
    "buCode": "SNJT",
    "buName": "水泥集团"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `ledgerId` | String | **是** | 台账主键 ID，从查询结果中获取 |
| 其他字段 | - | 是 | 同新增接口 |

> 流水号（`ledgerNo`）、创建信息（`createBy`/`createByName`/`createTime`）不允许通过此接口修改，即使传了也会被忽略。修改后 `publishTime`/`publishBy`/`publishByName` 会自动刷新为当前操作人和时间。

### 响应

```json
{
    "status": true,
    "code": "000000",
    "data": null
}
```

## 7. 删除台账（逻辑删除）

```
POST /gateway/e/business/source/collectionDailyAmountLedger/delete
```

### 请求参数

```json
{
    "ledgerId": "2075038425069625346"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `ledgerId` | String | **是** | 台账主键 ID |

> 删除为**逻辑删除**，数据库记录保留但标记为已删除，之后查询和详情接口都不会返回该记录。

### 响应

```json
{
    "status": true,
    "code": "000000",
    "data": null
}
```

# 四、字段完整说明

### 台账业务字段（新增/修改用）

| 字段 | 类型 | 新增必填 | 修改必填 | 来源 |
|------|------|----------|----------|------|
| `executeUnitCode` | String | 是 | 是 | 组织查询 `orgCode` |
| `executeUnitName` | String | 是 | 是 | 组织查询 `orgName` |
| `categoryCode` | String | 是 | 是 | 类目字典 `code` |
| `categoryName` | String | 是 | 是 | 类目字典 `name` |
| `statisticDate` | String | 是 | 是 | 日期选择器，格式 `yyyy-MM-dd` |

| `purchaseCompanyName` | String | 是 | 是 | 组织查询 `orgName` |
| `taxAmount` | BigDecimal | 是 | 是 | 手动输入 |

## 常见错误

| 场景 | 响应 |
|------|------|
| 修改/删除/详情时不传 `ledgerId` 或为空 | 业务异常，`msg` 为 `"台账主键不能为空"` |
| 记录已被逻辑删除后查详情 | `data` 中所有字段为 null |
| 记录已被逻辑删除后查列表 | 列表中不包含该记录 |
