# 11部分git仓库需要账号密码 — 排查与解决

- 日期：2026-08-12
- 工具：oc
- 当前状态：已解决，5 个 HTTP remote 全部改为 SSH
- 下一步：无，日常 clone 时注意用 `company-gitlab:` 别名

## 根因

所有仓库的免密/要密码差异只在 **remote URL 形式**：

- 免密的仓库：remote 是 SSH 别名 `company-gitlab:scm-zc/...`，经 `~/.ssh/config`（HostName 10.0.65.220, Port 55022, IdentityFile `~/.ssh/thinkpad-t14-wsl_ed25519`）走密钥认证，不弹密码。
- 要密码的仓库：remote 是 HTTP `http://10.0.65.220:9090/...`，HTTP 无凭据缓存（未装 credential helper），每次 pull/push 都要账号密码。

全局 git 配置无 credential helper（`~/.gitconfig` 只有 user.name/user.email 等）。

## 涉及仓库（5 个）

| 仓库 | 原 remote |
|---|---|
| 01zhaocai-end/scm-mdm-all | http://10.0.65.220:9090/scm-zc/scm-web/scm-mdm-all.git |
| 01zhaocai-end/scm-report-all | http://10.0.65.220:9090/scm-zc/scm-web/scm-report-all.git |
| 02zhaocai-front/scm-vue-all-mall-portal | http://10.0.65.220:9090/scm-zc/scm-vue/scm-vue-all-mall-portal.git |
| 02zhaocai-front/scm-vue-hpc | http://10.0.65.220:9090/scm-zc/scm-vue/scm-vue-hpc.git |
| 03zhaocai-start/scm-cloud-starters-wfproduct | http://10.0.65.220:9090/scm-zc/start/scm-cloud-starters-wfproduct.git |

其余 ~60 个仓库 remote 均已是 SSH 别名，无需处理。

## 解决

对 5 个仓库执行 `git remote set-url origin company-gitlab:<原路径>`，例如：

```bash
git -C 01zhaocai-end/scm-report-all remote set-url origin company-gitlab:scm-zc/scm-web/scm-report-all.git
```

验证：
- 修改后逐个 `git fetch origin` 全部成功、无认证提示（SSH 密钥权限本就存在，与其它仓库同一 GitLab）。
- `scm-all/.gitmodules` 的 submodule URL 均为 `ssh://git@10.0.65.220:55022/...`，本身免密，无需改。

## 后续注意

新 clone 仓库一律用 SSH 别名形式：`git clone company-gitlab:scm-zc/<组>/<仓>.git`，不要用 HTTP。
