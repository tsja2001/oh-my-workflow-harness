## 4. 拿到答案之后怎么查（先写着，别提前动手）

按 `skills/diagnose-scm-project/` 的路子走，顺序是：

1. 页面 → 接口（F12 抓一个请求）→ 哪个服务；
2. 服务 → 数据从哪张表/哪个 ES 索引读；
3. 那张表**最后一条数据是什么时候写的**（这一步直接判定"是不是没更新"）；
4. 如果写入靠定时任务：找到那个 job，看**最近一次执行时间和结果**；
5. 如果写入靠同步：看上游有没有数、同步链路断在哪。

**不要跳过第 1 步直接翻定时任务列表。**
