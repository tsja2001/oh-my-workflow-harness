## 单条版本

需要一条条贴给产品看时，把上面 `filters` 里对应那段的 `bool` 直接放进 `"query"` 即可，例如 D1：

```json
GET index_centralized_procurement_report_test/_search
{
  "size": 0,
  "track_total_hits": true,
  "query": {
    "bool": { "must": [
      { "range": { "bookTime": { "gte": "2026-01-01 00:00:00", "lt": "2026-08-10 00:00:00", "format": "yyyy-MM-dd HH:mm:ss", "time_zone": "+08:00" }}},
      { "term": { "dataSource": "FP" }},
      { "term": { "isCentralized": 1 }},
      { "term": { "supplierCode": "911302300759817983" }},
      { "bool": { "minimum_should_match": 1, "should": [
        { "prefix": { "categoryCode": "1501" }},{ "prefix": { "categoryCode": "1701" }},
        { "prefix": { "categoryCode": "2302" }},{ "prefix": { "categoryCode": "2502" }}]}}
    ]}
  },
  "aggs": { "金额": { "sum": { "field": "taxTotal" }}}
}
```

## 辅助查询

**① 把争议的那笔 24,720 明细捞出来**

```json
GET index_centralized_procurement_report_test/_search
{
  "size": 5,
  "query": { "term": { "taxTotal": 24720 }},
  "_source": ["bookTime","dataSource","isCentralized","purchaseType","buCode","buName","categoryCode","categoryName","supplierCode","supplierName","materialName","planCode","taxTotal"]
}
```

全库仅一条：2026-06-24、方钢 35×35、非平台录入、唐山冀东机电设备（911302300759817983）、水泥集团 BU002、类目 1501、24,720.00 元。

**② 验证「或采购业务类型属于集团/二级/区域集采」是否会多捞数据**

```json
GET index_centralized_procurement_report_test/_search
{
  "size": 0,
  "aggs": { "pt": { "terms": { "field": "purchaseType", "size": 20, "missing": "(空)" },
    "aggs": { "cent": { "terms": { "field": "isCentralized", "missing": -1 }}, "金额": { "sum": { "field": "taxTotal" }}}}}
}
```

实测：集团集采 534 条（全部 `isCentralized=1`）／分散采购 14 条／空 25 条。
**这个「或」条件一条都多捞不出来**，不是差异来源（`purchaseType` 是同步时由 `isCentralized` 派生的字段）。

**③ 验证前缀匹配 vs 精确匹配对扣减是否有影响**

把 D1 里那段 `prefix` 换成精确：

```json
{ "terms": { "categoryCode": ["1501","1701","2302","2502"] }}
```

实测两种写法都是 **1 条 / 24,720.00 元**，完全一样。

**④ 看各来源类目码位数（解释为什么前缀改动只影响云采）**

```json
GET index_centralized_procurement_report_test/_search
{
  "size": 0,
  "aggs": { "src": { "terms": { "field": "dataSource", "size": 10 },
    "aggs": { "cat": { "terms": { "field": "categoryCode", "size": 40, "missing": "(空)" },
      "aggs": { "金额": { "sum": { "field": "taxTotal" }}}}}}}
}
```

实测：MT/FP/JD/ZC 共 563 条全是四位大类码（前缀 ≡ 精确）；只有 YC 10 条是末级码（`250201`、`15010101`、`29020506`、`2121`）。
