## 3. 发现并修复的问题

| 现象 | 根因 | 修复 | 回归结果 |
|---|---|---|---|
| 完全不成形 token 被旧网关包装成 HTTP 500，没有走标准 401 | 网关先尝试解析坏 JWT | 读取缓存时先校验三段 JWT 形态，坏缓存不发送 | 坏缓存恢复通过 |
| 真实旧 token 返回的不是 `900301` | 项目登出/失效检查返回 `ERROR_JWT_INVALIDITY` | 自动重登白名单加入项目两类 JWT 错误码 | 真实旧 JWT 自动恢复通过 |
| 初次探针用临时文件清理被命令安全护栏拦截 | 探针含删除动作 | 改为响应只在内存中解析，不落 token 临时文件 | 后续四登录/八请求探针通过 |

## 5. 结论

功能可以投入当前 AI 自动开发/测试流程。它消除了人工刷新 token 的常规步骤，同时保留了账号变更、验证码变化和 prod 开放这三类必须由人确认的安全边界。
