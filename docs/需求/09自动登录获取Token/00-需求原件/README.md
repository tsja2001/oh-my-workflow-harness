## 脱敏后的需求原话

1. 自动登录并获取业务接口 token，不再人工把浏览器 token 粘进 `creds.env`。
2. 支持 test、UAT；每个环境同时覆盖招采、云采，环境内 token 可以复用。
3. 支持通用管理员、供应商两类账号；稳定账号密码只放受控凭据文件。
4. 当前 test/UAT 的图片验证码和短信验证码不校验；prod 暂不配置、不调用。
5. 目标是让 AI 自动开发/测试链路更顺、减少人工打断和重复 token 消耗。
