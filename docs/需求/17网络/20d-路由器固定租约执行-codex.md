路由器：中兴晴天 BE5100 Pro+。

静态地址绑定表新增 1 行：

| 项目 | 实际值 |
|---|---|
| 名称 | `Mac` |
| 设备标识 | 从路由器当前在线设备列表选择，和 `ifconfig en1` 的实际私有 Wi-Fi MAC 完全一致 |
| 固定 IP | `192.168.5.35` |
| 自定义网关 | `192.168.5.1` |

没有手工猜 MAC，也没有使用网卡永久硬件地址；使用的是路由器实际看到的当前 Wi-Fi 私有地址标识。

- DHCP 服务仍开启。
- DHCP 地址池未改。
- DHCP 租期仍为 86400 秒。
- DNS、备用 DNS、WAN、Wi-Fi、NAT、静态路由和 MESH 均未改。
- 没有重启路由器。

## 3. 写后回查

1. 提交后弹窗关闭，静态地址绑定表出现 `Mac`、`192.168.5.35`、`192.168.5.1`。
2. 重新加载路由器页面并再次展开局域网配置，该行仍存在。
3. 执行 `networksetup -setdhcp "Wi-Fi"` 触发 DHCP 续租。
4. `ipconfig getpacket en1` 回读：`yiaddr=192.168.5.35`、DHCP Server=`192.168.5.1`、租期 86400 秒。
5. 续租后默认网关仍为 `192.168.5.1`。

## 5. 恢复方式

如以后需要取消固定地址，只删除静态地址绑定表中名称为 `Mac`、IP 为 `192.168.5.35` 的这一行，然后让 Mac 重新 DHCP 续租。禁止重置路由器或改 DHCP 池。
