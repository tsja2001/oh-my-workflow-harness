我之前用的是tailscale，现在要换成Cloudflare方案：

公司电脑 → Cloudflare（你的域名）→ 家里设备上的 cloudflared → 本地服务（SSH / 网页等）

这是一个标准的 Cloudflare Tunnel（零信任隧道） 架构，核心思想是：家里主动出站连接 Cloudflare，公司侧永远只访问 Cloudflare 的公网入口，从而避免在家里开放端口，也避免公司网络直接看到家里 IP 或私有组网协议。
