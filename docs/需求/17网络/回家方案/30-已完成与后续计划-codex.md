## 推荐的下一步

1. 保持现状使用几天，SSH/VS Code 用 B，家庭 IP/网页用 A。
2. VS Code 只做一次真实小目录测试，记录连接耗时、输入卡顿、保存文件和断线情况；不必机械等待 30 分钟。
3. 如果真实工作仍明显卡，再安排 Mac 侧单变量测试，但必须同时满足：Mac 本地控制或带外入口、配置备份、定时自动回退、一次只改 Connector 路由、A/B/公司网络完整复验。
4. 如果没有明显收益，维持当前双通道，不继续增加复杂度。
